# Code-Cloner

Clone code patterns

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/Code-Cloner.git
cd Code-Cloner
go build -o code-cloner .
```

## Usage

```bash
.code-cloner .
.code-cloner --path ./src
```
